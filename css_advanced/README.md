# SmileSchool – CSS Advanced Project

This project is the continuation of the **HTML Advanced** module.  
Here, the focus is on **CSS styling** and recreating the full SmileSchool homepage exactly as designed in Figma.

---

##  Project Overview

The goal of this project is to transform the raw HTML structure from the previous “HTML, advanced” task into a fully styled and responsive webpage by applying CSS guided by the official Figma design.

You will recreate the **SmileSchool homepage**, including:

- A fixed header and navigation bar  
- A hero banner with background image and call-to-action  
- “Learn from the pros” instructor section  
- Testimonial section  
- Video tutorial cards  
- “Free membership” features  
- FAQ section  
- Footer section

The final result should match the Figma as closely as possible.

---

##  Figma Design

To complete this project, you must use the official design file provided by ALX.

-  **Figma page:** *https://www.figma.com/* (ALX SmileSchool design)  
- **Figma .fig file:** Provided for download  
- **Project images:** Provided in the resources package  

Make sure to **Duplicate to Drafts** to access layer styles, colors, spacing, fonts, and other design values.

>  Some Figma values are floats — rounding is allowed.

---

##  Technologies Used

- **HTML5** – Based on the structure provided in the previous project  
- **CSS3** – Focus of this task  
- **Flexbox / Grid**  
- **Figma** for design reference  
- **Images & assets** provided in the project resources  

Fonts used in this project:

- **Source Sans Pro**
- **Spin Cycle OT**

If your computer does not have these fonts, download and install them before styling.

##  Requirements

### General
- All styling must be written in **CSS**.
- The `index.html` file should be based on the original structure from the HTML advanced project (editing allowed).
- You must match the Figma as closely as possible.
- Use proper class naming for styling.
- Keep CSS clean, readable, and well-structured.

### Deliverables
- **README.md** (this file)
- **index.html**  
- All images placed in the correct folder

## How to Run the Project

1. Clone the repository:

```
git clone https://github.com/<your-username>/alx_html_css.git
```

2. Navigate to the project directory:

```
cd alx_html_css/css_advanced
```

3. Open the HTML file in your browser:

```
open index.html
```

or simply double-click the file.
